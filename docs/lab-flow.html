Flow của stack đã tạo

Một Lambda, gha-lambda-practice-images ở ap-southeast-1. HTTP API yêu cầu chữ ký IAM. Lambda ký URL để client đưa byte thẳng lên S3, rồi ghi s3_key vào RDS.

Request đi đâu

HTTP API POST /images trên ImagesUrl. API Gateway kiểm tra chữ ký, rồi gọi Lambda với event có requestContext.
→
Lambda images POST /images trả URL PUT hết hạn sau 60 giây. Sau khi file nằm trên S3, POST /images/{id}/complete mới INSERT dòng. GET, PATCH và DELETE đọc hoặc sửa dòng đó.
←
AppSync Query hello trên GraphQlUrl. AppSync kiểm tra chữ ký, resolver gọi Lambda với event có info.fieldName.

Một request HTTP

1
Client gọi ImagesUrl

POST /images đã ký SigV4, body JSON chỉ có name và content_type. Authorizer là AWS_IAM. Thiếu chữ ký thì cửa từ chối, Lambda không chạy. Byte ảnh không đi qua cửa này.

2
API Gateway chuyển event

Integration AWS_PROXY, payload format 1.0. Resource policy chỉ cho đúng API này gọi hàm.

3
Lambda trả vỏ HTTP

statusCode 201 và upload_url. Client PUT file lên URL đó. complete kiểm tra object rồi lưu dòng. GET /images/{id} ký URL xem, hết hạn sau 60 giây. DB không lưu URL.

Một query GraphQL

1
Client gửi query hello

POST tới GraphQlUrl, cũng ký SigV4. Authorization mode của API là AWS_IAM.

2
Resolver gọi Lambda

Data source là hàm hello. Event có info.fieldName bằng hello. Resource policy chỉ cho đúng API AppSync này.

3
Lambda trả object field

Hàm hiện tại không trả object cho query hello. AppSync chưa có trong Terraform. Cửa đang dùng là HTTP API.

Body GraphQL còn nguyên statusCode và body dạng chuỗi nghĩa là handler trả nhầm vỏ HTTP cho AppSync.

Hai tín hiệu stack đang sống

1
POST ImagesUrl

Body có ok: true, id và s3_key. Thiếu chữ ký thì Lambda không chạy.

2
GET /images/{id}

Cùng s3_key, URL mới hết hạn sau 60 giây. 404 nghĩa là dòng không có trong RDS.

Cả hai có service: gha-lambda-practice. Output function_name là gha-lambda-practice-images.
