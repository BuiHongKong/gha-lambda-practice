Flow của stack đã tạo

Một Lambda, gha-lambda-practice-hello ở ap-southeast-1. Hai cửa gọi vào cùng hàm: HTTP API và AppSync. Cả hai yêu cầu chữ ký IAM. Stack sống khi cả ba đường trả cùng một kết quả.

Request đi đâu

HTTP API GET /hello trên HelloUrl. API Gateway kiểm tra chữ ký, rồi gọi Lambda với event có requestContext.
→
Lambda hello Handler nhìn hình dạng event. Cửa HTTP nhận vỏ statusCode + body. Cửa GraphQL nhận object của field.
←
AppSync Query hello trên GraphQlUrl. AppSync kiểm tra chữ ký, resolver gọi Lambda với event có info.fieldName.

Một request HTTP

1
Client gọi HelloUrl

Request đã ký SigV4. Authorizer là AWS_IAM. Thiếu chữ ký thì cửa từ chối, Lambda không chạy.

2
API Gateway chuyển event

Integration AWS_PROXY, payload format 1.0. Resource policy chỉ cho đúng API này gọi hàm.

3
Lambda trả vỏ HTTP

statusCode 200, body là chuỗi JSON. API Gateway chuyển chuỗi đó thành response cho client.

Một query GraphQL

1
Client gửi query hello

POST tới GraphQlUrl, cũng ký SigV4. Authorization mode của API là AWS_IAM.

2
Resolver gọi Lambda

Data source là hàm hello. Event có info.fieldName bằng hello. Resource policy chỉ cho đúng API AppSync này.

3
Lambda trả object field

Giá trị trả về là {"ok": true, "message": "hello from lambda", ...}. AppSync gắn object đó vào data.hello.

Body GraphQL còn nguyên statusCode và body dạng chuỗi nghĩa là handler trả nhầm vỏ HTTP cho AppSync.

Ba tín hiệu stack đang sống

1
Invoke thẳng Lambda

Khớp thì code hàm ổn. Hỏng ở đây thì chưa cần nhìn hai cửa.

2
GET HelloUrl

Khớp thì HTTP API đang trỏ đúng hàm. URL có mà body sai nghĩa là route hoặc integration lệch.

3
Query hello trên GraphQlUrl

Khớp thì resolver AppSync đang trỏ đúng hàm.

Cả ba có ok: true, service: gha-lambda-practice, và function đúng tên hàm trong output của stack.

Output cần đọc

Output Dùng để
FunctionName Đối chiếu field function trong payload. Đúng tên thì đúng hàm đã deploy.
HelloUrl Gọi GET /hello qua API Gateway.
GraphQlUrl Gửi query hello qua AppSync.
